# Nomie Word Cloud v2

A word cloud from the words in your notes: emotions, virtues, the people you write about, or your own words. Shown on the dashboard.

Source: https://github.com/RdeLange/nomie-wordcloud-v2. Pages: https://dailynomie.github.io/nomie-wordcloud-v2/
